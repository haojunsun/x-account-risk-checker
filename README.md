# X 账号风险检查 Skill

让 AI 按流程检查 X（Twitter）账号的公开帖子与互动，整理风险线索、证据和调整建议。建议优先在 Grok 中使用其公开帖子搜索能力。

项目地址：https://github.com/haojunsun/x-account-risk-checker

## 检查内容

- 回复是否重复、缺少实质内容或与原帖无关。
- 发帖与互动是否过密、批量或机械。
- 原创表达、引用分析与内容同质化情况。
- 可见的关注相关信号、主题变化与引流行为。
- 根据实际材料判断低 / 中 / 高风险，并提出改进建议。

## 在 Grok 中使用（推荐）

1. 打开本仓库的 [SKILL.md](SKILL.md)，复制完整内容。
2. 打开 Grok 对话，将内容粘贴进去。
3. 在末尾加上以下要求，把用户名换成自己的账号：

```text
请按上面的 Skill 检查 @你的用户名 最近 7 天的公开帖子和回复。
请实际检索，说明检索时间、覆盖范围与样本数，并附代表性帖子链接。
区分观察事实、规则依据和推测，给出风险等级与最优先的 3 项调整。
若无法检索或证据不足，请明确说明并向我索取材料，不要编造。
以当前 X 官方规则为准，不把本文中的经验数量当作官方安全阈值。
不要仅凭浏览量、回复长短或关注/粉丝比例认定被限流；无法确认时直接说明。
```

这是把 Skill 作为任务指令使用，无需在 Grok 安装插件。Grok 是否能取得所需帖子取决于当前可用工具与实际搜索结果；不能假设已经遍历全部历史。没有搜索能力时，手动提供公开帖子链接、正文或脱敏截图。

Grok 公开搜索能力说明：https://help.x.com/en/using-x/about-grok

## 在支持 Skill 的助手中使用

将仓库放到所用客户端的技能目录，或要求助手读取 `SKILL.md`。能否自动取得 X 数据取决于客户端是否有对应工具；文档提到的工具名称不是本仓库实现的接口。

调用示例：

```text
使用 x-account-risk-checker，检查 @你的用户名 最近 7 天的账号风险；先说明能取得哪些数据，再开始分析。
```

## 判断边界

当前 `SKILL.md` 保留上传版本。其中行为影响排序、每日互动或关注数量、1—2 天观察期属于待验证的经验建议，不是已证实的算法权重、官方安全线或恢复承诺。短回复、低浏览量、关注比例、主题变化、使用第三方工具本身，均不足以单独证明违规或被限流。

本工具只能整理公开活动与用户提供材料中的风险线索，不能读取 X 内部评分或确认推荐限制状态。自动化用途应按具体规则判断；申诉按平台要求如实说明，不保证纯手动运营即可恢复账号。

规则参考：

- X 真实性政策：https://help.x.com/en/rules-and-policies/authenticity
- X 自动化规则：https://help.x.com/en/rules-and-policies/x-automation
